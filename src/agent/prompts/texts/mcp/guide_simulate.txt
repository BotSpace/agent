# Bot simulyatsiyasi (flow_simulate) — qo'llanma

flow_simulate flow'ni REAL engine kodi bilan, Telegram'siz ishga tushiradi:
har qadam bot javoblari, bajarilgan node yo'li, xatolar va yakuniy state qaytadi.
Default'da SAQLANMAGAN working draft sinaladi (use_saved=true — saqlangan flow).

## Step turlari (FAQAT shular — boshqa nom ishlatma)

| type           | Maydonlar                  | Tavsif |
|----------------|----------------------------|--------|
| `command`      | text="/start"              | Bot komandasi |
| `text`         | text="Ali Valiyev"         | Oddiy matn xabari |
| `click`        | data="order"               | INLINE tugma bosish — data = callback_data ("callback"/"button" EMAS!) |
| `click_text`   | text="📚 Kurslar"          | Tugma MATNI bo'yicha bosish (callback_data noma'lum yoki collection tugmasi bo'lsa) |
| `contact`      | phone="+9989...", first_name? | Kontakt yuborish (request_contact javobiga) |
| `location`     | latitude=41.31, longitude=69.24 | Joylashuv yuborish |
| `advance_time` | seconds=3600               | Vaqtni oldinga surish — CronTriggerNode'lar otiladi (schedule_message qamralmaydi) |

## Multi-user (referral va sh.k.)
Har qadamga ixtiyoriy `chat` qo'shsa bo'ladi — qadam o'sha user nomidan ketadi:
```json
{"type":"command","text":"/start u111","chat":{"id":222,"first_name":"Mehmon"}}
```
Bot javobidagi `chat_id` qaysi userga ketganini ko'rsatadi. Keyboard tarixi per-user.

## expect + mode="assert" (token tejash — ko'p qadamli tekshiruvda DOIM ishlat)
Har qadamga `expect` qo'shib, so'rovga `mode:"assert"` bering — javob kompakt
"✅ 9/10 o'tdi" + faqat yiqilgan qadamlar bo'ladi:
```json
{"type":"click","data":"order","expect":{"contains":"qaysi coffee","keyboard_contains":"Latte","no_errors":true}}
```
expect maydonlari: contains, not_contains, keyboard_contains (hammasi
katta-kichik harfga befarq; edit qilingan xabarlar ham tekshiriladi),
message_count, no_errors.

## To'liq misol (zakaz oqimi)
```json
{
  "mode": "assert",
  "steps": [
    {"type":"command","text":"/start","expect":{"keyboard_contains":"zakaz","no_errors":true}},
    {"type":"click","data":"order","expect":{"contains":"qaysi","no_errors":true}},
    {"type":"click_text","text":"Latte","expect":{"contains":"o'lcham"}},
    {"type":"text","text":"Ali Valiyev","expect":{"contains":"telefon"}},
    {"type":"contact","phone":"+998901234567","expect":{"contains":"qabul qilindi"}}
  ]
}
```

## Regression testlar
Ishlaydigan stsenariyni `flow_test_save(name, steps)` bilan saqlang — har
`flow_save` ularni avtomatik ishga tushiradi va regressiyani ushlaydi.
`flow_test_run` — qo'lda ishga tushirish, `flow_test_list` — ro'yxat.

## Cheklovlar
- Kolleksiyalar: `seed_collections=true` real hujjatlardan max 50 tadan nusxa
  oladi; simulyatsiyadagi yozuvlar REAL bazaga TA'SIR QILMAYDI (izolyatsiya).
- AI node'lar (LLM chaqiruvlar) va to'lovlar simulyatsiyada real ishlamaydi.
- schedule_message/SchedulerNode advance_time bilan otilmaydi.
