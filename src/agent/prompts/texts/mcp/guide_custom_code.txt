# CustomCodeNode JavaScript API — to'liq ma'lumotnoma

CustomCodeNode `data.jsCode` ichidagi JS Goja VM'da ishlaydi. Quyidagi global
o'zgaruvchilar va funksiyalar mavjud. (Node `data.outputs:[{name:"..."}]` e'lon
qiladi va kodda `exit("nom")` bilan keyingi qadamga yo'naltiradi; yagona chiziqli
yo'l uchun `outputs:[{name:"default"}]` + `exit("default")`.)

## ⚠️ KOD FORMATI — TOZA, O'QILADIGAN YOZ (engine saqlashda formatlamaydi!)
`jsCode` qanday yozsang, shundayligicha saqlanadi — engine/UI uni qayta
formatlamaydi. Shuning uchun BIRINCHI martda toza, o'qiladigan, "prettier"
ko'rinishida yoz. Minified yoki bir-qatorga tiqilgan kod YOZMA. Qoidalar:
- **Har statement alohida qatorda.** Bitta qatorga `;` bilan ko'p amal tiqma
  (`const a = 1; const b = 2;` EMAS — ikki qatorga ajrat).
- **Izchil 2-probel otступ.** `{ ... }` bloklar ichidagi qatorlarni bir pog'ona
  ichkariga sur; yopuvchi `}` ochuvchi qator bilan teng turadi.
- **Operator/qiymat atrofida bo'shliq:** `a = 1`, `x === y`, `i < n` (NE `a=1`,
  `x===y`). Vergul va `:` dan keyin bitta probel (`{ text: name, qty: 1 }`).
- **Mazmunli o'zgaruvchi nomlari** — `movie`, `episodes`, `phone` (bir harfli
  `m`/`e`/`p` EMAS); qisqa loop indeksigina (`i`) istisno.
- **Murakkab joyga qisqa izoh** (`// _id avto ObjectId bo'ladi`) — lekin har
  qatorga emas, faqat noaniq joyga.
- `if (cond) { exit('x'); return; }` ni AGAR qisqa bo'lsa bir qatorda qoldirsang
  ham bo'ladi, lekin tana 1+ amaldan oshsa bloklab yoz (har amal alohida qator).
- `exit('NAME')` va `return` uslubini saqla: branch'dan keyin `return` (quyidagi
  kod ishlamasin); linear (outputs yo'q) holatda `exit`/`return` shart emas.

### Toza format namunasi (SHUNGA TAQLID QIL)
```javascript
const phone = (message.contact && message.contact.phone_number) || '';
const digits = phone.replace(/\D/g, '');

if (digits.length < 9) {
  send_message('❌ Telefon raqami noto‘g‘ri.');
  exit('invalid');
  return;
}

const existing = db_find_one('users', { telegram_id: chat_id });
if (existing && existing.data) {
  set_context('user', existing.data);
  exit('existing');
  return;
}

const created = db_insert('users', {
  telegram_id: chat_id,
  phone: digits,
  created_at: current_timestamp(),
});
set_context('user_id', created.insertedId);
exit('new');
```

## Global o'zgaruvchilar
- `chat_id` (number) — joriy chat id
- `message` (object) — kelgan xabar: `.text`, `.first_name`, `.contact.phone_number`,
  `.location.latitude/.longitude`, `.photo`, `.document` ...
- `callback_query` (object) — inline tugma bosilganda: `.data` (callback_data),
  `.message_id` va `.message.message_id` (TUGMA TURGAN XABAR id — edit uchun!),
  `.message.text`, `.first_name`
- `context` (object) — barcha kontekst kalitlari. **O'qish uchun AFZAL usul:
  obyekt-access** `context.<key>` (`context.first_name`, `context.user_id`,
  `context.sheets_response_rows`, `context.collection_<key>`,
  `context.message_id_<nodeId>` — har send-node yuborgan xabar id). Qisqa va toza.
- `vars` (object) — OCHIQ (public) saqlangan qiymatlar. **AFZAL: `vars.<key>`** —
  ichida `public_` prefiks AVTOMATIK qo'shiladi (toza nom yoz). `vars.user_phone` ≡
  `context.public_user_phone`. Node maydonidagi `{{user_phone}}` (yoki
  `{{public.user_phone}}`) bilan bir xil. O'qish HAM yozish: `vars.x = v`.
- `state` (object) — `vars` ning LEGACY aliasi, HALI ishlaydi (`public_` ga map
  qiladi). Yangi kodda `vars.<key>` yoz; `state.<key>` faqat orqaga moslik uchun.
- `private` (object) — MAXFIY (private) qiymatlar (token, parol, sirli kod).
  `private.api_token` ≡ `context.private_api_token`, node'da `{{private.api_token}}`.
  Maxfiy ma'lumotni shu yerda saqla, ochiq `vars`ga emas.
- `command_args` (string) — `/start ABC` da "ABC" (argumentsiz "")

## Flow boshqaruv
- `exit(name)` — kodni to'xtatib `output-<name>` edge'iga yo'naltiradi
- `wait_for_input()` — pauza, foydalanuvchi javobini kutadi (node BOSHIDAN qayta
  ishga tushadi — step'ni `set_context` bilan saqla)
- `sleep(ms)`

## Ochiq o'zgaruvchilar (vars — TAVSIYA, prefiks avtomatik)
StateNode/trigger saqlagan OCHIQ qiymatlar node maydonlarida `{{name}}` (yoki
`{{public.name}}` / legacy `{{state.name}}`) ko'rinishida o'qiladi (ichida
`public_` prefiks bilan saqlanadi).
**O'QISH/YOZISH — `vars.<key>` obyekt-access afzal** (qisqa, toza):
```javascript
const phone = vars.user_phone;       // ≡ get_state("user_phone")
const code = vars.movie_code;
vars.movie_code = code;              // yozish — node'da {{movie_code}}
```
- YOZISH: `set_state(key, value)` → bool yoki `vars.key = value` (`public_` ga
  yoziladi ⇒ node'da `{{key}}`)
- O'QISH (muqobil funksiya): `get_state("movie_code")` — `vars.movie_code` bilan bir xil
- `has_state(key)`, `delete_state(key)`
- Prefiksni QO'LDA yozma — `vars.x` / `set_state("x", ...)` ikkalasi ham
  `public_` ni avtomatik qo'shadi (toza nom ber).
- `state.x` — `vars.x` ning LEGACY aliasi, HALI ishlaydi (ikkalasi `public_` ga;
  legacy `state_` prefiks ham hanuz o'qiladi). Yangi kodda `vars.x` afzal.

## Maxfiy o'zgaruvchilar (private)
Token, parol, sirli/bir martalik kod — `vars` (ochiq) emas, `private` ga saqla:
```javascript
private.api_token = token;           // public_ EMAS, private_ ga yoziladi
const token = private.api_token;     // o'qish
```
Node maydonida `{{private.api_token}}` bilan o'qiladi. Maxfiy qiymatni xabar
matnida yalang'och `{{api_token}}` bilan AKS ETTIRMA.

## Kontekst (xom kalit — prefiks YO'Q)
**O'QISH — `context.<key>` obyekt-access afzal** (qisqa, toza):
```javascript
const firstName = context.first_name;          // ≡ get_context("first_name")
const rows = context.sheets_response_rows;
```
- YOZISH: `set_context(key, value)` → bool (kalitni o'zgartirmaydi; node'da `{{key}}`)
- O'QISH (muqobil funksiya): `get_context("first_name")` — obyekt-access bilan bir xil
- `has_context(key)`, `delete_context(key)`, `get_all_context()`
- Eslatma: `vars.x` ≡ `context.public_x` (legacy `state.x` ham `public_x` ga);
  `private.x` ≡ `context.private_x`; `set_state("x", v)` ≡ `set_context("public_x", v)`

## Xabar yuborish / tahrirlash
- `send_message("matn")` yoki `send_message("matn", {parse_mode, inline_keyboard, reply_keyboard, remove_keyboard})`
  yoki `send_message({text, parse_mode, inline_keyboard, ...})` → `{success, message_id}`
- `edit_message_text(options)` — MAVJUD xabarni tahrirlaydi. options:
  `{text, parse_mode?, reply_markup?, message_id?, node_id?}`.
  Qaysi xabar tahrirlanishini aniqlash (biri):
    • `message_id: 123` — aniq xabar id
    • `node_id: "welcome"` — o'sha node yuborgan xabar (`message_id_welcome` dan)
    • IKKALASI HAM berilmasa va callback kontekst bo'lsa — TUGMA TURGAN xabar
      (`callback_query.message.message_id`) avtomatik tahrirlanadi
- `edit_or_send(options)` — **EditOrSend node'ning JS ekvivalenti**: mumkin bo'lsa
  EDIT qiladi, bo'lmasa YANGI xabar yuboradi. options: `{text, parse_mode?,
  reply_markup?, node_id?, message_id?}`. Pagination/menyu yangilash uchun ENG QULAY.
- `send_photo/send_video/send_document/send_audio/send_voice/send_sticker/
  send_location/send_contact/send_animation(options)`
- `delete_message(options)`, `answer_callback_query(text?)`, `forward_message`, `copy_message`

### inline_keyboard / reply_markup formati
`inline_keyboard: [[{text, callback_data}], [{text, url}]]` — qatorlar massivi.
`reply_markup` formati ham qabul qilinadi: `{type:"inline", buttons:[[...]]}`.
Web App tugma: `{text, type:"web_app", value:"https://..."}` (faqat https; inline va
reply ikkalasida) — `value` URL string yoki `{url:"..."}`:
`inline_keyboard: [[{text:"Ochish", type:"web_app", value:"https://app.example.com"}]]`

## Raw Telegram Bot API (tg_call + wrapper'lar)
- `tg_call(method, params)` — ISTALGAN Telegram Bot API metodi. Nested
  ob'ekt/massiv (reply_markup, permissions, prices...) avto JSON-string. →
  `{ok, result}` yoki `{ok:false, description}`. `params.chat_id` berilmasa joriy chat.
  ```javascript
  tg_call('banChatMember', { chat_id: -1001234567890, user_id: user_id });
  tg_call('sendInvoice', { title:'Premium', description:'1 oy', payload:'p1',
    provider_token:'', currency:'XTR', prices:[{label:'Narx', amount:100}] });
  ```
- Nomli wrapper'lar (bir xil `{ok,result}`; chat_id ixtiyoriy = joriy chat):
  guruh — `ban_chat_member`, `unban_chat_member`, `restrict_chat_member`,
  `promote_chat_member`, `get_chat`, `get_chat_member`, `get_chat_member_count`,
  `set_chat_title`, `set_chat_description`, `create_chat_invite_link`,
  `approve_chat_join_request`, `decline_chat_join_request`
  (ESLATMA: qo'shilish so'rovini tasdiqlash/rad etish uchun endi alohida
  ApproveChatJoinRequestNode/DeclineChatJoinRequestNode node'lari bor — CustomCode
  o'rniga ularni ishlat; chatId/userId bo'sh qoldirilsa trigger context'idan oladi); to'lov —
  `send_invoice`, `answer_pre_checkout_query`, `answer_shipping_query`,
  `refund_star_payment`; boshqa — `set_message_reaction`, `create_forum_topic`,
  `close_forum_topic`.

## MongoDB (collection)
- `db_find_one(collection, filter?)` → `{success, data}`  (data=hujjat yoki null)
- `db_find(collection, filter?, {limit, skip, sort}?)` → `{success, data:[...]}`
- `db_insert(collection, document)` → `{success, insertedId}`
- `db_update(collection, filter, update)` → `{success, modifiedCount}`  ($set/$inc bilan)
- `db_delete(collection, filter)` → `{success, deletedCount}`
- `db_count(collection, filter?)` → `{success, count}`
- `_id` bo'yicha qidirishda 24-belgili hex string avtomatik ObjectId'ga aylanadi:
  `db_find_one("movies", {_id: id})` ishlaydi.

## HTTP
- `http_request({url, method, headers?, body?})`, `http_get/http_post/http_put/http_delete`

## Alert (kuzatuv — constructor "Xabarlar" paneli)
Debug "Xabarlar" paneliga leveled signal yuboradi. Flow ijrosiga TA'SIR QILMAYDI
(fire-and-forget — xato qaytarmaydi, oqimni to'xtatmaydi). Kuzatuv (observability)
uchun: muhim hodisa → info, shubhali holat → warning, jiddiy muammo → error.
- `alert.info(msg, detail?)`, `alert.warning(msg, detail?)`, `alert.error(msg, detail?)`
- `detail` ixtiyoriy (texnik tafsilot/stack). Obyekt/array berilsa JSON ko'rinishida chiqadi.
```javascript
alert.info('Foydalanuvchi ro'yxatdan o'tdi: ' + user_id);
try { http_post(url, body); } catch (e) { alert.error('To'lov xatosi', e.message); }
```

## Stdlib
`date_today, date_now, date_format, date_parse, date_add, date_diff, hash_md5,
hash_sha256, hmac_sha256, base64_encode, base64_decode, url_encode, random,
random_int, random_choice, current_timestamp`

✅ **Bugungi sana/vaqt — `date_today()` / `date_now()` (TAVSIYA, eng oson):**
- `date_today()` → `"YYYY-MM-DD"` (UTC), masalan `"2026-06-18"`. Argumentsiz.
- `date_now()` → `"YYYY-MM-DD HH:mm:ss"` (UTC), masalan `"2026-06-18 14:30:00"`.
  Argumentsiz. `occurred_at`/log/o'qiladigan timestamp matni uchun shuni ishlat.
Bular format token yozishni talab qilmaydi — xatosi kam, BIRINCHI tanlov.
Misol: `db_insert('logs', {occurred_at: date_now(), msg: 'ok'})`.

⚠️ **`date_format(ts, fmt)` — MUQOBIL (formatni o'zing boshqarganda).** TOKEN
formati, Go layout EMAS. Faqat shu tokenlar almashtiriladi: `YYYY MM DD HH mm ss`.
Misollar:
- Bugungi sana: `date_format(current_timestamp(), 'YYYY-MM-DD')` → `2026-06-18` (≡ `date_today()`)
- Sana + vaqt: `date_format(current_timestamp(), 'YYYY-MM-DD HH:mm:ss')` (≡ `date_now()`)
Go layout (`'2006-01-02'`, `'15:04:05'`) BERMA — u tan olinmaydi va literal
`2006-01-02` matni qaytadi. `date_parse` esa `'YYYY-MM-DD'` yoki
`'YYYY-MM-DD HH:mm:ss'` (yoki RFC3339) ni Unix vaqtga o'giradi.
`created_at`/`occurred_at` maydonlariga RAQAMLI Unix vaqt kerak bo'lsa
`current_timestamp()` saqla; o'qiladigan sana MATNI kerak bo'lsa
`date_today()` / `date_now()` (yoki `date_format`) bilan formatla.

## NAMUNA: kod bo'yicha pagination (EDIT-IN-PLACE)
Foydalanuvchi kod yuboradi → ro'yxat chiqadi → Keyingi/Oldingi O'SHA xabarni
tahrirlaydi (yangi xabar yubormaydi). Sir: callback'da `edit_or_send` yoki
`edit_message_text` argumentsiz — ikkalasi ham callback xabarini o'zi topadi.

```javascript
// show-list node (kod kiritilganda VA page: callback'da — ikkala holatda ishlaydi)
const PAGE_SIZE = 5;
const callbackParts = (callback_query && (callback_query.data || '').split(':')) || [];
const code = String(vars.movie_code || callbackParts[1] || '').trim();  // o'qish: obyekt-access (vars afzal)
const requestedPage = parseInt(callbackParts[2] || 1, 10);

const movie = db_find_one('movies', { code: code });
if (!movie || !movie.data) {
  edit_or_send({ text: '❌ Kod topilmadi.' });
  exit('default');
  return;
}

const episodes = (db_find('episodes', { code: code }).data || [])
  .sort((a, b) => (a.episode_no || 0) - (b.episode_no || 0));
const pageCount = Math.max(1, Math.ceil(episodes.length / PAGE_SIZE));
const page = Math.min(Math.max(requestedPage, 1), pageCount);
const chunk = episodes.slice((page - 1) * PAGE_SIZE, page * PAGE_SIZE);

let text = '🎬 <b>' + movie.data.title + '</b>';
text += '\nJami: ' + episodes.length + ' qism';
text += '\nSahifa: ' + page + '/' + pageCount;

const rows = chunk.map((episode) => [
  { text: '▶️ ' + episode.episode_no + '-qism', callback_data: 'ep:' + episode._id },
]);

const nav = [];
if (page > 1) {
  nav.push({ text: '⬅️ Oldingi', callback_data: 'page:' + code + ':' + (page - 1) });
}
if (page < pageCount) {
  nav.push({ text: 'Keyingi ➡️', callback_data: 'page:' + code + ':' + (page + 1) });
}
if (nav.length) {
  rows.push(nav);
}

if (callback_query) {
  answer_callback_query('Sahifa ' + page);
}
edit_or_send({ text: text, parse_mode: 'HTML', inline_keyboard: rows });
exit('default');
```
Bitta `page:` global CallbackQueryTriggerNode (filter:starts_with, value:"page:")
→ shu node'ga ulanadi. Kod kiritish (MessageTrigger) ham shu node'ga ulanadi.

> ⚠️ Dinamik tugmali ro'yxatni statik tugma topib o'tira olmaysiz — pagination,
> filter foydalanuvchi kiritmasiga bog'liq bo'lsa CustomCode + edit_or_send ishlat.
> Lekin OD­DIY statik collection ro'yxati uchun EditOrSendMessageNode'ning
> `collectionData` (server-side pagination) yetarli — CustomCode YOZMA.
