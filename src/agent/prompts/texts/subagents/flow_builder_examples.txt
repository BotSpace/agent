REAL BOT MISOLLARI — bot qurish uchun namuna tool call ketma-ketliklari
════════════════════════════════════════════════════════════════════════════

Bu fayldagi har misol noldan to flow.save'gacha to'liq, ishlaydigan tool call
zanjiri. Yangi misol qo'shganda quyidagi OLTIN QOIDALARga amal qil:

  1. ROOT NODE = kam bo'lsin. Root node — bu trigger'dan boshqa hech qaysi
     node'ga ulanmagan kirish nuqtasi. Faqat shular root bo'lishi mumkin:
       • Command trigger'lar (/start, /admin, /help) — har biri bitta root.
       • CronNode (vaqt bo'yicha ishga tushadigan) — root.
     Menu/inline tugma uchun ALOHIDA root trigger YARATMA.

  2. INLINE TUGMA → Approach A (to'g'ridan-to'g'ri edge), trigger node YO'Q.
     Tugma `value` beradi, undan keyingi node'ga `flow.connect(... source_handle=
     "target-handler-<node>-<text>")`. Bu eng ko'p uchraydigan stsenariy.

  3. GLOBAL TRIGGER faqat AYNI BITTA tugma KO'P joydan bosilganda (masalan
     "⬅️ Ortga" hamma sahifada). Shunda BITTA global trigger oqlanadi —
     har sahifaga alohida emas. Global bo'lsa ham u mantiqan bir nuqtaga
     (menu'ga) olib boradi, osilib qolmaydi.

  4. CustomCode dinamik tugma yuborsa (db'dan kelgan ro'yxat), callback'ni
     ushlash uchun `CallbackQueryTriggerNode(global:false)` + CustomCode'dan
     unga `flow.connect` edge. Edge'siz trigger ISHLAMAYDI.

  5. Har misol QURISHDAN OLDIN talabni intent → spec'ga aylantiradi (0-QADAM).
     Quyidagi 2 namuna talab → intent talqini → spec → tool call zanjirini
     ko'rsatadi. Spec'da YO'Q narsani qo'shma.

MISOL 2 — Dinamik katalog + buyurtma (collection'dan)
════════════════════════════════════════════════════════════════════════════
Stsenariy: /start → mahsulotlar (db'dan dinamik) → tanlanganda detal →
"Buyurtma" → ism/telefon so'rab buyurtma saqlash.
Avval `cms.*` bilan collection O'ZING yaratilgan deb faraz qilinadi.

```python
# Turn 1: node'lar
flow.add_command_trigger(id="start", data={"command": "/start", "global": True})
flow.add_custom_code(
    id="list-products",
    data={
        "jsCode": "const res = db_find('products', {active: true}); const items = (res && res.data) || []; if (!items.length) { send_message('Hozircha mahsulot yo\\'q.'); exit('default'); return; } const rows = items.map(function(p) { return [{ text: p.name + ' — ' + p.price + ' so\\'m', callback_data: 'prod:' + p._id }]; }); send_message('🛍 <b>Mahsulotlar:</b>', { parse_mode: 'HTML', inline_keyboard: rows }); exit('default');",
        "outputs": [{"name": "default"}]
    },
    after="start"
)
# CustomCode dinamik tugma yubordi → callback'ni ushlash uchun non-global trigger (Qoida 4)
flow.add_callback_query_trigger(
    id="prod-cb",
    data={"filter": "starts_with", "context": {"value": "prod:"}, "global": False}
)
flow.add_custom_code(
    id="product-detail",
    data={
        "jsCode": "const id = callback_query.data.replace('prod:', ''); const res = db_find_one('products', {_id: id}); if (!res || !res.data) { send_message('Topilmadi.'); exit('default'); return; } const p = res.data; set_context('order_product_id', id); set_context('order_product_name', p.name); send_message('<b>' + p.name + '</b>\\n\\n' + (p.description || '') + '\\n\\n💰 ' + p.price + ' so\\'m', { parse_mode: 'HTML', inline_keyboard: [[{ text: '🛒 Buyurtma berish', callback_data: 'buy:' + id }]] }); exit('default');",
        "outputs": [{"name": "default"}]
    },
    after="prod-cb"
)
flow.add_callback_query_trigger(
    id="buy-cb",
    data={"filter": "starts_with", "context": {"value": "buy:"}, "global": False}
)
flow.add_node(
    id="ask-name",
    type="SendTextMessageNode",
    data={"messageText": "✍️ Ismingizni yozing:"},
    after="buy-cb"
)
flow.add_message_trigger(
    id="capture-name",
    data={"global": False, "filter": "any", "state": {"key": "order_name", "type": "text"}}
)
flow.add_node(
    id="ask-phone",
    type="SendTextMessageNode",
    data={
        "messageText": "📱 Telefon raqamingizni yuboring:",
        "keyboard_kind": "reply",
        "rows": [{"columns": [{"text": "📱 Telefon yuborish", "type": "request_contact"}]}]
    }
)
flow.add_message_trigger(
    id="capture-phone",
    data={"global": False, "filter": "any", "state": {"key": "order_phone", "type": "contact_phone_number"}}
)
flow.add_custom_code(
    id="save-order",
    data={
        "jsCode": "const order = { name: get_context('order_name'), phone: get_context('order_phone'), product_id: get_context('order_product_id'), product_name: get_context('order_product_name'), telegram_id: chat_id, status: 'new', created_at: current_timestamp() }; const ins = db_insert('orders', order); if (ins && ins.success) { send_message('✅ Buyurtmangiz qabul qilindi!\\n\\n📦 ' + order.product_name + '\\n👤 ' + order.name + '\\n📱 ' + order.phone + '\\n\\nTez orada bog\\'lanamiz.', { parse_mode: 'HTML' }); } else { send_message('❌ Xatolik. Qaytadan urinib ko\\'ring.'); }",
        "outputs": []
    },
    after="capture-phone"
)

# Turn 2: edge'lar — har CustomCode dan keyingi node'ga aniq edge (Qoida 4)
flow.connect(source="start", target="list-products")
flow.connect(source="list-products", target="prod-cb")
flow.connect(source="prod-cb", target="product-detail")
flow.connect(source="product-detail", target="buy-cb")
flow.connect(source="buy-cb", target="ask-name")
flow.connect(source="ask-name", target="capture-name")
flow.connect(source="capture-name", target="ask-phone")
flow.connect(source="ask-phone", target="capture-phone")
flow.connect(source="capture-phone", target="save-order")

# Turn 3-4
flow.validate()
flow.save()
```

Root node soni: 1 (faqat start). Barcha boshqa trigger'lar (prod-cb, buy-cb,
capture-name, capture-phone) NON-GLOBAL va oldingi node'ga edge bilan ulangan.


════════════════════════════════════════════════════════════════════════════
MISOL 3 — AI yordamchi bot (LLM + RAG)
════════════════════════════════════════════════════════════════════════════
Stsenariy: /start salom → har matn AIAgentNode'ga → Ollama + knowledge tool
javob beradi. Ollama provider credential'i `credentials.list(type_key="ollama")`
bilan topilgan (yoki `credentials.create` bilan yaratilgan) deb faraz qilinadi —
provider `credential_id` orqali bog'lanadi, qo'lda apiKey EMAS.

```python
# Turn 1: trigger + agent + reply
flow.add_command_trigger(id="start", data={"command": "/start", "global": True})
flow.add_node(
    id="welcome",
    type="EditOrSendMessageNode",
    data={"messageText": "Salom, {{first_name}}! 🤖\nSavolingizni yozing — javob beraman.", "parseMode": "HTML"},
    after="start"
)
flow.add_message_trigger(
    id="user-msg",
    data={"global": True, "state": {"key": "question", "type": "text"}}
)
flow.add_ai_agent(
    id="agent",
    data={
        "systemPrompt": "Sen yordamchi botsisan. O'zbek tilida qisqa va aniq javob ber. Bilmagan narsangni ayt.",
        "outputKey": "agent_output",
        "returnMode": "text"
    },
    after="user-msg"
)
flow.add_node(
    id="reply",
    type="EditOrSendMessageNode",
    data={"messageText": "{{agent_output}}"},
    after="agent"
)

# Turn 2: accessory node'lar (flow edge KERAK EMAS)
# Provider credential_id orqali (credentials.list(type_key="ollama") dan id) — qo'lda apiKey EMAS.
flow.add_ai_ollama_provider(
    id="provider",
    data={"provider": "ollama", "model": "gpt-oss:120b", "credential_id": 12}  # base_url credential'dan keladi — SET QILMA
)
flow.add_ai_knowledge_tool(
    id="kb",
    data={"tool": "knowledge", "collection": "faq", "topK": 5, "embeddingProvider": "ollama", "embeddingModel": "nomic-embed-text", "embeddingApiKey": "<user-key>"}
)

# Turn 3: edge'lar + accessory ulash
flow.connect(source="start", target="welcome")
flow.connect(source="user-msg", target="agent")
flow.connect_accessory(accessory_id="provider", agent_id="agent", port="acc:ai_model")
flow.connect_accessory(accessory_id="kb", agent_id="agent", port="acc:ai_tool")

# Turn 4-5
flow.validate()
flow.save()
```

Root node soni: 2 (start + user-msg). user-msg global — chunki har xabar
trigger'i flow giriş nuqtasi, mantiqan oqlanadi.

════════════════════════════════════════════════════════════════════════════
TALAB: "ikki tilli (o'zbek/rus) bot, /start'da til so'rasin, keyin salom".
SPEC: tillar ["uz","ru"], default "uz"; /start → til tanlash (public_lang) →
marker-obyekt salom. Har user-facing matn marker. (0-QADAM 6-band: i18n.)

```python
# Turn 0: tillarni o'rnat — MAJBURIY BIRINCHI (aks holda i18n ishlamaydi)
flow.set_languages(languages=["uz", "ru"], default_language="uz")

# Turn 1: /start → til tanlash (public_lang ga saqlaydi)
flow.add_command_trigger(id="start", data={"command": "/start", "global": True})

    id_prefix="lang",
    state_key="lang",            # → public_lang
    style="inline",
    after="start",
    question={"__i18n": True, "uz": "Tilni tanlang:", "ru": "Выберите язык:"},

        {"text": "🇺🇿 O'zbekcha", "value": "uz"},
        {"text": "🇷🇺 Русский", "value": "ru"}

)
# Til tanlangach — marker-obyekt salom (engine public_lang bo'yicha yassilaydi)
flow.add_node(
    id="welcome",
    type="EditOrSendMessageNode",
    data={
        "parseMode": "HTML",
        "messageText": {
            "__i18n": True,
            "uz": "<b>Assalomu alaykum, {{first_name}}! 👋</b>\n\nBotga xush kelibsiz.",
            "ru": "<b>Здравствуйте, {{first_name}}! 👋</b>\n\nДобро пожаловать в бот."

# Turn 2: edge — til capture'dan salomga
flow.connect(source="lang-capture", target="welcome")

# Turn 3
flow.validate()
flow.save()
```

Root node soni: 1 (start). Eslatma: callback `value` ("uz"/"ru") va id'lar
marker EMAS — faqat oddiy string. Salom matni marker → har user o'z tilida ko'radi.


════════════════════════════════════════════════════════════════════════════
ROOT NODE TEKSHIRUVI (har bot uchun yakunda o'zingni tekshir)
════════════════════════════════════════════════════════════════════════════
flow.save oldidan o'zingga savol ber:
  • Nechta node hech qaysi edge'ning target'i EMAS (ya'ni root)?
  • Ular HAMMASI command trigger / cron / mantiqan oqlangan global message
    trigger / 1ta umumiy "back" trigger'mi?
  • Agar menu tugmasi uchun alohida global trigger root bo'lib osilib qolgan
    bo'lsa — uni O'CHIR, o'rniga menu node'idan Approach A edge tort.
Ko'p root node = yomon dizayn. Ideal: 1–3 root (asosan command'lar).
