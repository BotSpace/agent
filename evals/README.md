# Ordinary-user blueprint evaluations

`ordinary_user_intents.json` contains intentionally non-technical Uzbek prompts,
including common spelling omissions. `tests/unit/test_blueprint_intent_evals.py`
is a release gate: every prompt must rank its expected registered blueprint
first. Add real failed user prompts here before fixing ranking or adding a new
blueprint, so the failure cannot return in a later release.

This deterministic intent gate complements flow semantic validation and the
engine simulator journey generated by `flow.build_blueprint`.
